# Sandboxed playgrounds

> A consequence-free environment where users can try an agent's capabilities before granting real access.

## Overview

Nobody hands car keys to a stranger. Sandboxes let users watch the agent work on sample data, simulated accounts, or reversible copies, building an accurate mental model before anything real is at stake.

## Why it works

Direct experience beats documentation. A safe rehearsal converts abstract capability claims into observed behaviour, which is how humans actually calibrate trust.

## When to use it

- High-stakes domains (money, legal, production systems)
- Capability-rich agents users underestimate or overestimate
- Sales and onboarding moments

## When to avoid it

- When the sandbox behaves differently enough from production to teach the wrong model

## Examples in the wild

- Stripe test mode as the archetype
- OpenAI Playground for model behaviour
- Demo workspaces in analytics and CRM products
