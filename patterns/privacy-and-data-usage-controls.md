# Privacy & data usage controls

> Clear, actionable controls over what data the agent accesses and how it is used, including for training.

## Overview

The question users actually ask ('what happens to my stuff?') deserves a first-class answer. This pattern pairs plain-language disclosure with real controls: per-source access, training opt-outs, retention windows, one-tap revocation.

## Why it works

Data confidence is a precondition for the deep access agents need to be useful. Opacity caps how much users will ever connect.

## When to use it

- Agents reading personal or corporate accounts
- Products training on user interactions
- Jurisdictions with data-protection regimes

## When to avoid it

- Consent theatre: walls of text with a single Accept button

## Examples in the wild

- Training-data opt-outs in ChatGPT's data controls
- Apple's privacy nutrition labels as disclosure prior art
- Granular connector permissions in workspace AI tools
