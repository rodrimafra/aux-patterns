# Activity timeline & audit log

> A chronological, filterable record of everything the agent did, with enough detail to reconstruct decisions.

## Overview

Trust needs receipts. The timeline records actions, inputs, outputs, and approvals, readable by the user who delegated and by the organisation accountable for the result.

## Why it works

Auditability converts agent work from anecdote into evidence. It powers debugging, dispute resolution, compliance, and the confidence to delegate more.

## When to use it

- Autonomous actions on real systems
- Team environments where others review agent work
- Compliance-bound industries

## When to avoid it

- Raw log dumps posing as user-facing timelines, curation is the design work

## Examples in the wild

- Devin's session timeline
- Zapier task history
- GitHub Actions run logs as developer prior art
