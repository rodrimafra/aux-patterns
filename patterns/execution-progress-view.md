# Execution progress view

> A live map of a multi-step task: what is done, what is happening, what remains.

## Overview

For long tasks, users need situational awareness, not just a spinner. The progress view shows the plan with per-step status (complete, running, blocked) so the human can supervise at a glance and intervene precisely.

## Why it works

Visible structure turns waiting into monitoring. Users spot stalls and wrong turns mid-run, when intervention is cheap.

## When to use it

- Tasks with three or more meaningful steps
- Background work users check on periodically
- Handoffs where a colleague resumes supervision

## When to avoid it

- Trivial tasks where a progress apparatus outweighs the work

## Examples in the wild

- Task checklists in agentic coding sessions
- Devin's plan view with live step status
- Deployment pipeline stage views
