# Tool usage indicators

> Visible signals showing which tool or source the agent is using at each moment.

## Overview

When an agent searches the web, runs code, or reads a file, the interface says so. Tool badges make the invisible supply chain of an answer legible.

## Why it works

Knowing the method lets users judge the answer. 'From a web search' and 'from memory' warrant different scepticism, and visible tool use teaches capability in passing.

## When to use it

- Multi-tool agents mixing sources of varying reliability
- Auditable and regulated contexts
- Capability discovery in early use

## When to avoid it

- Overloading every response with badge clutter for single-tool tasks

## Examples in the wild

- 'Searching the web…' indicators in chat assistants
- Source chips on grounded answers
- Tool-call labels in agent execution logs
