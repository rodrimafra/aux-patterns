# Teach-me interfaces

> The agent demonstrates and explains how to work with it, turning instruction into interaction.

## Overview

Instead of shipping a manual, the agent is the manual. It walks users through its own capabilities with live examples, explains why an approach worked, and coaches better delegation over time.

## Why it works

People learn tools by using them with a guide. An agent that teaches its own operation compresses time-to-competence and reduces abandoned first sessions.

## When to use it

- Novel interaction paradigms with no inherited conventions
- Complex capability that rewards skilled prompting
- Re-onboarding after major capability changes

## When to avoid it

- When teaching moments interrupt rather than serve the current task

## Examples in the wild

- Duolingo Max explaining answers rather than just marking them
- Interactive product tours driven by real user data
- Copilot explaining a suggested change on request
