# Risk & policy heatmaps

> A visual overlay showing where agent activity touches sensitive data, systems, and decisions.

## Overview

Not all agent work carries equal risk. The heatmap maps activity against sensitivity (which agents touch PII, move money, face customers) so oversight attention lands where exposure actually is.

## Why it works

Governance by heatmap replaces governance by anecdote. Compliance effort gets allocated by measured exposure, not by whoever shouted last.

## When to use it

- Regulated industries deploying agents broadly
- Risk assessments preceding new agent capabilities
- Audit preparation and evidence

## When to avoid it

- Startups with two agents and no compliance surface, premature machinery

## Examples in the wild

- Cloud security posture dashboards as prior art
- DLP consoles mapping sensitive data flows
- Model-risk registers in financial institutions
