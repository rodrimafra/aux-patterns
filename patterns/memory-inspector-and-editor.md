# Memory inspector & editor

> A place to see, correct, and delete everything the agent remembers about you.

## Overview

Memory without inspection is surveillance. The inspector lists remembered facts in plain language (where each came from, what it affects) with edit and delete as first-class actions.

## Why it works

Visible, editable memory converts personalisation from creepy to collaborative. Users who can prune memory will let more of it grow.

## When to use it

- Persistent assistants that accumulate user facts
- Personalisation whose effects users notice
- Privacy-sensitive deployments

## When to avoid it

- Raw embedding dumps posing as 'memory transparency'

## Examples in the wild

- ChatGPT's manage-memories interface
- Remembered-preference lists in voice assistants
- Ad preference managers as flawed prior art
