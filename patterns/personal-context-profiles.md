# Personal context profiles

> The agent's working model of the individual user (role, goals, situation) held open for inspection and correction.

## Overview

Every adaptive agent forms a theory of its user. This pattern makes that theory explicit: 'here is who I think you are and what you're trying to do', editable, and visibly connected to how behaviour changes.

## Why it works

An inspectable user model transforms personalisation from inference done to you into a profile maintained with you. Corrections improve the agent faster than any signal it could mine.

## When to use it

- Long-relationship assistants adapting to their user
- Role-dependent behaviour (founder vs. accountant vs. counsel)
- Onboarding flows that infer context from connected data

## When to avoid it

- Sensitive inferred traits that should never be modelled, let alone displayed

## Examples in the wild

- Inferred-interest profiles opened for editing (ad settings, done right)
- Taste profiles in recommendation products
- Role-based personalisation in onboarding flows
