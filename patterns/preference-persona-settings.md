# Preference persona settings

> Durable, explicit settings for how the agent should behave: tone, verbosity, defaults, boundaries.

## Overview

Users shouldn't re-litigate style every session. Persona settings capture standing preferences (terse or thorough, formal or warm, always-ask or just-do) applied consistently and overridable per task.

## Why it works

Explicit preferences beat inferred ones for trust: the user wrote the rule, so the behaviour reads as obedience rather than profiling.

## When to use it

- Daily-use assistants across varied tasks
- Teams standardising agent behaviour
- Accessibility needs (reading level, verbosity, format)

## When to avoid it

- Settings sprawl duplicating what in-context requests handle better

## Examples in the wild

- Custom instructions in ChatGPT
- Style presets in writing assistants
- Per-project agent rules files in coding tools
