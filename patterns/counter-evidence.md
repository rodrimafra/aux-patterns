# Counter-evidence

> The agent surfaces what contradicts its own answer, not just what supports it.

## Overview

Confirmation is easy to generate; balance has to be designed. This pattern obliges the agent to show dissenting sources, conflicting data, and the strongest case against its conclusion.

## Why it works

A system that argues against itself earns a different order of trust. Counter-evidence inoculates users against automation bias, the tendency to stop thinking once the machine has spoken.

## When to use it

- Consequential decisions (medical, financial, legal, hiring)
- Contested topics with genuinely mixed evidence
- Analyst workflows where the user owns the conclusion

## When to avoid it

- Manufacturing false balance where evidence is genuinely one-sided

## Examples in the wild

- Conflicting-source flags in research assistants
- 'Top critical review' surfaced beside praise
- Devil's-advocate modes in decision-support tools
