# Multiple presented options

> The agent offers several candidate outputs instead of a single answer.

## Overview

One answer claims authority; several candidates invite judgement. Presenting alternatives shows the space of possibility, hands the final call to the human, and hedges against a single wrong guess.

## Why it works

Choosing among options is easier and more accurate than evaluating one answer in isolation, and selection data teaches the agent user preferences for free.

## When to use it

- Creative and subjective outputs
- Ambiguous requests with several valid readings
- Preference learning phases

## When to avoid it

- Factual questions with one right answer, options manufacture false doubt

## Examples in the wild

- Four-image grids in image generators
- Multiple suggestion panels in code assistants
- Three-chip smart replies in email
