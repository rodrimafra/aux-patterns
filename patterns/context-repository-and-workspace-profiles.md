# Context repository & workspace profiles

> Scoped, shared context (files, facts, conventions) attached to a project or team rather than a conversation.

## Overview

Context that dies with the chat is context users must keep re-supplying. Repositories give context a durable home: project knowledge, style guides, key documents, loaded automatically wherever that work continues.

## Why it works

Scoping context to workspaces matches how work is actually organised, and keeps personal, project, and organisational knowledge from bleeding into each other.

## When to use it

- Long-running projects with accumulated context
- Teams sharing one agent across members
- Consultants juggling clients whose contexts must not mix

## When to avoid it

- Single-conversation tasks that need no persistence

## Examples in the wild

- Claude Projects and ChatGPT Projects
- Workspace-level AI context in Notion
- Repository rules files consumed by coding agents
