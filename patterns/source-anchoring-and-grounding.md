# Source anchoring & grounding

> Every claim links to the source it came from, inspectable in one step.

## Overview

Ungrounded fluency is the core failure mode of generative systems. Anchoring pins each assertion to a citation (document, page, message) so verification is a click, not an investigation.

## Why it works

Citations shift the trust question from 'do I believe the agent' to 'do I believe the source', a question humans already know how to answer.

## When to use it

- Research, legal, medical, financial outputs
- Answers derived from user documents
- Any claim a user will repeat to someone else

## When to avoid it

- Decorative citations that do not actually support the anchored claim

## Examples in the wild

- Perplexity's inline citations
- NotebookLM's passage-level source anchors
- Footnoted answers in grounded enterprise search
